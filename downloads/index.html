Sequentia Core

version 25.2.6

The full node and its desktop wallet, with BTC and every Sequentia asset side by side. It checks every block for itself, and block producers run it.

Linuxx86-64, tarball Windows64-bit installer macOSBuild from source
What it does, install and update
  • Wallet: send, receive and issue assets; the Sequence token (tSEQ) is one asset among them.
  • Staking tab: committee schedule, stake weights and staking-output tools.
  • Anchor watching: follows Bitcoin testnet4 and reorgs when it does.
  • Any-asset fees: pay a fee in whichever asset a producer accepts.

Install: on Linux, extract the tarball and run bin/sequentia-qt. On Windows, run the installer, then launch Sequentia Core. It connects to the testnet on its own.

Update: install the newer release the same way. The wallet and the chain data stay where they are.

On a Mac: build Sequentia Core from source.

Files: sequentia-core-25.2.6-linux-x86_64.tar.gz, sequentia-core-25.2.6-win64-setup.exe

Fulmen

version 0.2.1

A desktop Lightning wallet for Sequentia and Bitcoin testnet4, with a full SeqLN node bundled in.

Linuxx86-64, AppImage Windows64-bit installer Windows64-bit portable zip
What it does and install
  • SeqLN: the Lightning network on Sequentia. Point Fulmen at a Sequentia node on first run; add a Bitcoin node to use Lightning on testnet4 too.
  • Asset channels: Lightning channels in BTC and in issued assets.
  • Any-asset payments: pay asset= chooses what a payment moves.
  • Per-asset balances: channel liquidity broken out by asset.
  • Windows: the node runs inside WSL2, installed on demand.

Install: on Linux, make the .AppImage executable and run it. On Windows, run the installer (one click, for your user account), or unzip the portable zip and run Fulmen.exe.

Files: Fulmen-0.2.1-linux-x86_64.AppImage, Fulmen-Setup-0.2.1.exe, Fulmen-0.2.1-win64.zip

Seqognito

version 0.1.0

A wallet for mixing: your coins join one transaction with other people's and come out at addresses nobody can link to them, every amount hidden.

Linuxx86-64, AppImage Windows64-bit installer Windows64-bit portable zip
What it does, what it hides and install
  • Wallet: it holds Bitcoin and Sequentia assets, and receives and sends. Your change is hidden as well.
  • Everything over Tor: the wallet sends only through a SOCKS proxy, and its window has no network of its own.
  • Two Tor circuits: your coins and your mixed addresses register over separate circuits, so the coordinator sees two strangers.
  • Your own nodes: point it at the Sequentia and Bitcoin endpoints you choose, .onion included.
  • Bitcoin too: parent-chain BTC is bridged in, mixed, and sent out to an address you have never used.

What it hides: the chain sees no amounts. The coordinator cannot link your coins to your mixed outputs; it does see your amounts and your change. Your anonymity set is the round you were in: a round of two people hides you among two.

Install: Tor must be running, as a system tor daemon (port 9050) or Tor Browser (9150). On Linux, make the .AppImage executable and run it. On Windows, run the installer, or unzip the portable zip. On first start it asks which nodes to use and encrypts your recovery phrase with a passphrase.

Files: Seqognito-0.1.0-linux-x86_64.AppImage, Seqognito-Setup-0.1.0.exe, Seqognito-0.1.0-win64.zip

Ambra mobile

version 0.17.29

A self-custody Android wallet for Bitcoin testnet4 and Sequentia, from one recovery phrase.

Androidarm64 and x86-64, APK
What it does, install and update
  • Both chains: BTC beside every Sequentia asset, on one shared tb1 address.
  • Total first: one portfolio total in your reference currency, every asset an equal row.
  • Send and receive: any-asset fees, opt-in confidential addresses, RBF and CPFP rescue.
  • Issue assets: create and reissue your own, including OpenAMP restricted assets.
  • SeqDEX terminal: market and limit orders, same-chain or cross-chain, on-chain or over Lightning.
  • Biometric lock and staking, built on SWK, the Sequentia Wallet Kit.

Install: allow “install unknown apps” for your browser, then open the .apk.

Update: open the newer .apk the same way. It installs over the old one and keeps the wallet.

Ambra browser

version 0.5.95

The same wallet as an extension for Chrome and other Chromium browsers, which websites can ask to connect, sign and pay.

ChromeOr any Chromium browser, extension zip
What it does, install and update
  • For websites: the window.sequentia API lets a site ask the wallet to connect, sign and pay.
  • One seed, both chains: Bitcoin testnet4 and Sequentia share the same address.
  • Portfolio total: multi-asset balances with any-asset fees on send.
  • Lightning: for BTC and for issued assets.
  • OpenAMP: hold and transfer issuer-governed restricted assets.

Install: unzip the download, open chrome://extensions, turn on Developer mode, click Load unpacked and select the unzipped folder.

Update: unzip the new download into the same folder, replacing its files, then click the reload arrow on Ambra in chrome://extensions. The wallet stays as it was. A new folder loaded beside the old one is a second copy of Ambra, which opens without your wallet until you import its recovery phrase.

Source on GitHub

Pignus CLI

version 0.3.0

Collateralised lending from the command line, against your own node: everything Pignus's lending site does, and a check of every vault before you sign.

Linux and macOSPython 3, source archive
What it does and install
  • Every loan step: propose a loan, publish a funded offer, borrow, repay, liquidate.
  • Verify before you sign: pignus-cli verify rebuilds the vault address from your terms and refuses if one atom of the debt, the strike or the oracle differs.
  • Run your own oracle: sign prices for your own markets and publish every attestation, so a liquidation can always be checked afterwards.
  • Run your own liquidator: liquidation is a permissionless race that anyone may enter.

Inside: pignus-cli, pignus-oracle, pignus-liquidator and pignusd.

Install: pure Python, with no build step. It needs a Sequentia source checkout, because the loan covenant lives in the node repository and Pignus imports its proven builder: set SEQUENTIA_SRC and run tests/cli_drill.sh to check the wiring.

Source on GitHub

Check your download Every file is listed in one checksum list, signed by the release key.
  1. Download SHA256SUMS, its signature SHA256SUMS.asc and the release signing key into the folder that holds your download.
  2. Import the key and check its fingerprint reads B4F5 7796 7E32 25D5 8FF6 3DFC 5974 FD59 E609 F11F, the same as in the release publisher's README. 
    gpg --import sequentia-release-signing-key.asc
  3. Check the signature; it must say Good signature. 
    gpg --verify SHA256SUMS.asc SHA256SUMS
  4. Check your file; it must say OK. 
    sha256sum --ignore-missing -c SHA256SUMS
    On a Mac, use shasum -a 256 --ignore-missing -c SHA256SUMS. On Windows, run certutil -hashfile with the file's name and SHA256, and compare the result with that file's line in SHA256SUMS; Gpg4win provides gpg for steps 2 and 3.
