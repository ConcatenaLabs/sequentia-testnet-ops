Wallet: send, receive and issue assets; tSEQ is one asset among them.
Staking tab: committee schedule, stake weights and staking-output tools.
Anchor watching: follows Bitcoin testnet4 and reorgs when it does.
Any-asset fees: pay a fee in whichever asset a producer accepts.

Install · Linux: extract the tarball and run bin/sequentia-qt. Windows: run the installer, then launch Sequentia Core. It connects to the testnet on its own.
